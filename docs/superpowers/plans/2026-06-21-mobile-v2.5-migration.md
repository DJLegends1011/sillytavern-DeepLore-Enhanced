# Mobile v2.5 Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Historical checkbox note:** Checkbox state is preserved as-authored and may not reflect current branch state; validate before using it as execution status.

**Goal:** Rebuild `codex-mobile-hybrid-shell` on `origin/staging`, remove PR #30 from its ancestry, and preserve the verified mobile UI on v2.5's Verdict, lifecycle, styling, and English-i18n contracts.

**Architecture:** Preserve the seven existing `src/mobile/` presentation modules, add one pure adapter for reading current-chat Verdict data, and inject v2.5 runtime services from `index.js`. Build in an isolated worktree on the existing mobile branch after saving a backup ref, then publish only after automated, browser, and Android verification.

**Tech Stack:** JavaScript ES modules, SillyTavern extension APIs, DeepLore `VerdictStore`, Node test harnesses, ESLint 9, in-app Browser QA, Android emulator QA, Git worktrees.

---

## Source map

- `src/mobile/mobile-shell.js`: browser lifecycle, providers, mobile event routing, and composition.
- `src/mobile/mobile-verdict.js`: new pure boundary that normalizes current-chat Verdict data and subscriptions.
- `src/mobile/mobile-i18n.js`: new pure boundary that delegates to v2.5 `tr`/`trf` while retaining English fallbacks in headless tests.
- `src/mobile/mobile-overlay.js`: pure overlay/header/tab/quick-action rendering.
- `src/mobile/mobile-fab.js`: floating action button placement and SillyTavern surface avoidance.
- `src/mobile/mobile-state.js`: local overlay state.
- `src/mobile/mobile-browse.js`: pure Browse filtering and row derivation.
- `src/mobile/mobile-injection.js`: pure Injection filtering, timers, and row derivation.
- `src/mobile/mobile-stats.js`: pure status metrics.
- `index.js`: owns v2.5 lifecycle and injects current-chat services.
- `style.css`: receives only the old branch's mobile block, reconciled with v2.5 tokens.
- `src/ui/setup-wizard.js`: receives the five-line mobile page-scroll behavior.
- `locales/dle.en.json`: canonical English mobile keys only.

- [ ] **Step 3: Implement the adapter**

Create `src/mobile/mobile-verdict.js`:

```js
const EMPTY = Object.freeze({
    chatId: null,
    msgIdx: -1,
    injectedSources: Object.freeze([]),
    trace: null,
});

export function normalizeMobileVerdict(verdict) {
    if (!verdict || typeof verdict !== 'object') return EMPTY;
    return {
        chatId: verdict.chatId ?? null,
        msgIdx: Number.isInteger(verdict.msgIdx) ? verdict.msgIdx : -1,
        injectedSources: Array.isArray(verdict.injectedSources) ? verdict.injectedSources : [],
        trace: verdict.trace && typeof verdict.trace === 'object' ? verdict.trace : null,
    };
}

export function readMobileVerdict(getCurrentVerdict) {
    try {
        return normalizeMobileVerdict(typeof getCurrentVerdict === 'function' ? getCurrentVerdict() : null);
    } catch {
        return normalizeMobileVerdict(null);
    }
}

export function subscribeMobileVerdict(onVerdictChanged, callback) {
    if (typeof onVerdictChanged !== 'function' || typeof callback !== 'function') return () => {};
    const unsubscribe = onVerdictChanged(callback);
    return typeof unsubscribe === 'function' ? unsubscribe : () => {};
}
```

export async function runMobileReroll({
    resetSearchCache = resetAiSearchCache,
    readMetadata = readMetadataApi,
    notify = (message) => globalThis.toastr?.info?.(message, 'DeepLore'),
} = {}) {

- [ ] **Step 3: Implement the pure adapter**

Create `src/mobile/mobile-i18n.js`:

```js
let translate = null;
let format = null;

function fallbackFormat(template, args) {
    return String(template ?? '').replace(/\$\{(\d+)\}/g, (_, index) => String(args[Number(index)] ?? ''));
}

export function configureMobileI18n(options = {}) {
    translate = typeof options.translate === 'function' ? options.translate : null;
    format = typeof options.format === 'function' ? options.format : null;
}

export function resetMobileI18n() {
    translate = null;
    format = null;
}

export function mt(key, fallback) {
    try { return translate?.(key, fallback) ?? fallback; } catch { return fallback; }
}

export function mtf(key, fallback, ...args) {
    try { return format?.(key, ...args) ?? fallbackFormat(fallback, args); }
    catch { return fallbackFormat(fallback, args); }
}
```
